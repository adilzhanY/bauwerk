# Bauwerk

A browser-based 3D building editor. Draw a footprint, stack storeys, cut windows and doors into the walls, split storeys into rooms, group rooms into zones, undo anything, and export the model as JSON. Built with Vite, React 18, TypeScript, Zustand, Three.js (react-three-fiber) and Tailwind CSS v4. Every geometry function is pure TypeScript with Vitest tests.

## Run

```
npm install
npm run dev        # start the dev server
npm run check      # typecheck, lint, tests
npm run build      # production build in dist/
npm run preview    # serve the production build
```
